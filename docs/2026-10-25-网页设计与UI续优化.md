# JobCompass 网页设计与 UI 续优化

日期：2026-10-25。基于现有 v2.0 云端功能与穆夏 v2「版画纸」规范，继续优化列表、筛选、表单和键盘操作。

## 设计方向

沿用象牙纸 `#f7f2e6`、深青 `#085844`、主墨 `#1f1e1a`、辅助墨 `#5f5d54` 与金线 `#c9a65c`。楷体承担标题，无衬线承担记录与操作，Georgia 仅用于字标。欢迎海报仍是全站唯一主视觉；日常列表用对齐、留白和分隔线建立层级。

列表从上到下为「标题与添加入口 → 搜索与排序 → 状态筛选 → 公司与岗位 / 日期 / 进度 / 操作」。桌面以固定辅助列对齐，手机改为上方记录信息、下方状态与操作。没有新增业务模块、主视觉图片或装饰组件。

## 本轮改动

- 「添加投递」移到标题右侧，统一深青胶囊与内嵌金线；显示公司数和投递数，手机补充进行中与 Offer 数量。
- 桌面列表增加列标题，日期与更新时间独立成列，岗位、状态、操作保持对齐。
- 手机状态筛选默认收起，展开后可多选；收起时仍显示所选状态摘要，可一键清除。选中项增加勾选图标。
- 统一手机上分组公司与单岗位公司的头像位置，分组展开箭头移到右侧。
- 修复分页只识别「是否筛选」的问题：关键词、具体状态集合或排序变化都会回到第一页；分页按钮增大至 40px，补充分页导航语义。
- 分组偏好写入 localStorage 失败时，当前页面仍能正常展开与折叠。
- 抽屉使用暖纸底和金线分隔，表单输入、主要操作增至 44px；手机输入字体 16px，辅助说明提高对比度。底栏适配设备安全区。
- 新增 `src/lib/useDialog.ts`，供抽屉、弹窗与欢迎层共用：打开聚焦、Tab 循环、Esc 关闭、关闭后回归入口、嵌套时只处理最上层，并正确维护背景滚动锁。
- 欢迎层补充模态语义，窄屏短视口下可完整滚动浏览；尊重减少动态效果设置。
- 登录与注册表单关联 label/id、补充密码管理器自动填充语义和错误播报；主列表增加键盘跳转链接。

- Edge **24 项**界面与键盘检查通过：1440 / 390 / 320px 无横向溢出；分组与单岗位头像对齐；分页、具体状态集合变更后的页码重置、手机筛选、抽屉焦点与 Esc、嵌套弹窗 Tab/Esc/焦点回归及滚动锁；浏览器无未捕获异常。
- 实际查看桌面列表、手机列表、手机抽屉与短视口欢迎层截图，并保存登录页、注册页截图。
- `npx tsc -b --force`、`npm run lint` 通过。
- `npm test`：3 文件、37 条单测通过。
- `npm run build` 通过，含 PWA 产物：JS **559.69 kB**、CSS **56.15 kB**；precache **14 项 / 668.75 KiB**。保留既有单包大于 500 kB 提示。

构建插件访问系统临时目录、浏览器启动均在获得工具批准后执行。上述 Edge 验证属于模拟数据的 UI 验收，不代替真实 Supabase 读写、多设备 Realtime、PWA 安装或移动设备真机测试。
