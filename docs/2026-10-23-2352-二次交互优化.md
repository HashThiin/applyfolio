## 二、编辑抽屉的标签页结构

打开任意记录的**编辑**：

```
┌─────────────────────────────┐
│ 编辑投递  ·  字节跳动 · 后端 │
├─────────────────────────────┤
│ [题目 / 备注] [编辑信息]     │  ← 标签栏（默认落在「题目」）
│                             │
│  ▸ 记录 1（历史，在上）      │
│  ▸ 记录 2                   │
│  ▸ ...                     │
│  ┌ 添加一条新记录 ┐          │  ← 输入区固定在下方
│  └ [添加记录]    ┘          │
├─────────────────────────────┤
│                    [关闭]   │
└─────────────────────────────┘
```

- **题目 / 备注** 标签：即时保存，底部按钮变为「关闭」。
- **编辑信息** 标签：字段表单，底部按钮「取消 / 保存修改」。
- 新建投递时不显示标签栏（因为还没有 application_id 无法挂题目）。

## 三、编辑多岗位（追加兄弟记录）

- 编辑模式第一行 = 当前记录的岗位（可改，可删不可空）。
- 「追加岗位」按钮：填第 2、3... 行 → 保存时会**以同一份公司/URL/日期/渠道/颜色/状态**新建记录。
- Toast 提示："已保存修改 · 新增 N 条同公司记录"。
- 删除限制：编辑模式下 index 0 的行不可删除，只能清空后由校验兜住；追加行可自由删除。

## 四、色块 & 置顶

### 色块

- 之前：头像色块 + 左侧 1px 竖条 + 名称旁小圆点（重复）。
- 现在：**只保留头像色块**，直接用 `record.color` 作 background + 白字。视觉更集中。

### 置顶

- 数据字段：`pinned BOOLEAN NOT NULL DEFAULT FALSE`。
- UI：动作列最左侧新增 📌 按钮
  - 已置顶：indigo 色，常亮。
  - 未置顶：淡灰，hover/移动端可见。
- 交互：点击 → 立即写入数据库；toast 提示"已置顶 / 已取消置顶"。
- 排序（在 `useApplications.filterAndSort`）：
  ```
  1. pinned 优先（true 排前面）
  2. 状态：非 rejected/withdrawn 优先（已挂/已放弃沉底）
  3. 用户选定排序：applied_at / updated_at / company
  ```

## 六、上线操作（必读）

### 1) 执行迁移 SQL

Supabase → SQL Editor → 粘贴并运行：

```sql
-- supabase/migrations/004_pinned.sql
ALTER TABLE applications
  ADD COLUMN IF NOT EXISTS pinned BOOLEAN NOT NULL DEFAULT FALSE;

CREATE INDEX IF NOT EXISTS idx_applications_user_pinned
  ON applications(user_id, pinned DESC, applied_at DESC);
```

**没有执行迁移前，点击 📌 按钮会返回 42703 错误**（列不存在）。其他功能不受影响，但为了完整体验请先跑这段。

### 2) 部署

```powershell
cd d:\job\app; vercel --prod --yes
```
