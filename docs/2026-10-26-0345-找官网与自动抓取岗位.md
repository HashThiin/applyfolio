# 2026-10-26 03:45 · v3.1 「投递」面板改版：只去企业校招官网，岗位信息自动抓取

> 用户两条要求：
> 1. 「找岗位」改成**页面居中的 UI**，简洁明了；收录意向相关的内容（公司/岗位/岗位要求）**不用手工填，由系统抓取**。
> 2. 要能走到**「企业名 + 校园招聘」的官网**，而不是招聘软件。
>
> 拍板结果：服务端抓取 + 剪贴板兜底；必应/百度/Google 三引擎 + 常用企业校招官网直达；抓到后**回填表单、用户扫一眼再收录**。

---

## 一、为什么「抓取」必须放在服务端

浏览器直接 `fetch` 别的站点会被 CORS 拦死（对方不返回 `Access-Control-Allow-Origin`），
所以「前端点一下就把岗位页读回来」在纯前端方案里不成立。三条路：

| 方案 | 覆盖 | 代价 |
|---|---|---|
| **服务端抓取**（Edge Function fetch + 解析） | 服务端渲染页、带 JSON-LD 的站 | 纯前端渲染（SPA）的校招站只有空壳 HTML |
| **剪贴板**（用户在岗位页 Ctrl+A / Ctrl+C） | 全部，含 SPA 与需要登录的站 | 需要用户复制一次 |
| 浏览器扩展 | 全部 | 要装插件，另立项 |

最终两者都做：先抓，抓不到自动引导复制。

## 二、搜索入口：不再指向招聘软件

`src/lib/jobSearch.ts` 重写：

- 移除 BOSS直聘 / 猎聘 / 前程无忧 / 智联。
- 三个引擎：`必应(cn.bing.com)` / `百度` / `Google`，查询词统一为
  **`{企业名或关键词} 校园招聘 官网`**（`buildCampusQuery`）。
- 选中引擎记在 `localStorage['af-search-engine']`，下次打开沿用。
- `CAMPUS_SITES`：12 家常用企业的校招官网直达（腾讯/字节/阿里/华为/美团/京东/网易/百度/拼多多/小米/快手/哔哩哔哩），
  输入企业名时按名字过滤（`filterCampusSites`）。链接会随企业改版失效，失效时用搜索即可，不为此加逻辑。

## 三、抓取链路（Edge Function `analyze-job` 新增 `action: 'scrape'`）

不新建第二个函数：`analyze-job` 现在按 `payload.action` 分流，
`scrape` 走 `supabase/functions/analyze-job/scrape.ts`，`analyze`（默认）保持原逻辑。
这样**只需要一次 `functions deploy`**。

处理顺序（逐级降级，任一级拿到就停）：

1. **JSON-LD `JobPosting`**：`<script type="application/ld+json">` → `@type` 含 `JobPosting`（支持 `@graph` 嵌套）→
   取 `title` / `hiringOrganization.name` / `description`（HTML 转纯文本）。
2. **`og:title` / `og:site_name` / `<title>`**：按 `-` `|` `·` 拆「岗位 - 企业」，并去掉「校园招聘」「招聘官网」等后缀。
3. **正文切片**：去 script/style/注释 → 去标签 → 找「岗位职责 / 工作职责 / 职位描述 / 任职要求」等标记，
   切到「投递方式 / 招聘流程 / 联系我们」为止。
4. **AI 兜底**：前三步拿不全 且 配了 `DEEPSEEK_API_KEY` 时，把页面正文前 6000 字交给 `deepseek-chat`
   抽 `{company, role, jdText}`（temperature 0、`json_object`、45s 超时）。失败静默跳过。

安全与边界：

- 只允许 `http/https`；`localhost`、`127.`、`10.`、`192.168.`、`172.16-31.`、`169.254.`、`::1`、`*.local|*.internal` 一律拒绝（`SCRAPE_BLOCKED_HOST`），
  重定向后的最终 URL 再校验一次。
- 抓取 20s 超时，HTML 截断 400 000 字符，正文截断 12 000 字符，JD 输出上限 8000 字符。
- 只收 HTML / XML / text 响应，二进制直接判 `SCRAPE_NOT_HTML`。
- 抓回的内容**只用于填表和给 AI 读**，不落库；用户确认后写的仍然是自己数据库里的记录。

可展示的错误码：`SCRAPE_BAD_URL` / `SCRAPE_BLOCKED_HOST` / `SCRAPE_TIMEOUT` / `SCRAPE_HTTP_ERROR`(403/404/其他) /
`SCRAPE_NOT_HTML` / `SCRAPE_EMPTY` / `SCRAPE_UNUSABLE` / `SCRAPE_FAILED`。
前端一律翻译成「改用复制整页文字」。

## 四、剪贴板兜底（`src/lib/clipboardJob.ts`，纯函数）

`parseJobPageText(raw)`：

- 带标签时取标签值：`公司名称|企业名称|招聘单位|公司|企业`、`岗位名称|职位名称|招聘岗位|岗位|职位`。
- 无标签时：跳过导航词（首页/登录/注册…）与网址行，取前 6 行里第一个 3–40 字的行当岗位名；
  前 12 行里含「有限公司/集团/科技/银行/股份…」的短行当公司名。
- `jdText` = 整页文字压缩后截断到 8000 字 —— 不做精细切分，交给 AI 的 prompt 去挑重点（丢信息比留噪音更糟）。
- `pickUrlFromText(raw)`：只从剪贴板取网址。

## 五、UI：居中对话框，三段式

`components/Modal.tsx` 扩展为可居中、可滚动的对话框（`size: 'sm' | 'lg'`），
头部/底部固定、中间区域自己滚动；`IntentPanel` 由右侧 Drawer 改为 `size="lg"` 的居中面板：

```
① 找企业校招官网   [企业名输入] [搜官网]      引擎：必应 百度 Google
                  常用校招官网：腾讯 字节 阿里 华为 …
② 从岗位页自动抓取 [粘贴岗位页网址] [剪贴板] [抓取]
③ 确认收录         公司 / 岗位 / 岗位网址 / 岗位要求（自动填好，可改）   [读剪贴板]
页脚：手动记一条 ………………………………………… [只收录] [收录并分析]
```

- 抓取成功后提示「已抓取（用 AI 整理过）：公司 · 岗位；职责与要求已填好，扫一眼再收录」。
- 抓取失败提示「…。也可以在岗位页按 Ctrl+A 全选、Ctrl+C 复制，再点剪贴板按钮」。
- 网页与抓取都不用 `window.open` 直连任意网址（原「打开」按钮已去掉）：入口只有搜索与官网直达。
