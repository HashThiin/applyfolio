# 2026-10-26 个人中心新增「自我评价」

## 一、需求与结论

在个人主页 `/me` 增加「自我评价」：一段可反复修改的定位陈述（方向、亮点、短板），**保存到 Supabase**，换设备/换浏览器后可读回。

关键取向：

- **显式保存而非自动保存**：一段长文边写边写库没有收益，反而会和本地草稿状态互相干扰；输入框下方给出「有未保存的修改 / 保存中… / 已保存 · 时间」状态行。
- **一用户一行，主键即 `user_id`**：用 `upsert(onConflict: 'user_id')` 免去「先查再插/改」的分支。
- **清空也是合法保存**：`self_evaluation TEXT NOT NULL DEFAULT ''`，空串即清空（Supabase 的 `TEXT NOT NULL` 允许空串，无需额外迁移）。
- **不做本地草稿**：与题目面板的 localStorage 草稿不同，自我评价是低频长文、且落库即有版本；未保存时状态行常驻提示即可。

### 交互与状态细节

- 进页面用微任务调度发起读取，规避 effect 内同步 setState；`cancelled` 标记防止卸载后回写。
- 脏判定按 `value.trim() !== savedValue`：行尾空格不算改动。
- 保存成功后**不用服务端返回值覆盖输入框**（保存期间可能还在敲字），只更新 `savedValue` 与保存时间。
- `42P01`（表不存在）单独提示「数据库缺少 user_profiles 表，请先执行 005_user_profile.sql」，其余失败提示「内容仍保留在输入框」。
- 样式沿用现有令牌：输入框 `border-ink-200` + 聚焦 `brand-600` / `ring-brand-600/15`，主按钮 `brand-800` 实底 + `text-page`；未保存/保存中/已保存文案为 `ink-600`（达标对比度），错误态 `red-700`。
