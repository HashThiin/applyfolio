# JobCompass 穆夏书册重设计

日期：2026-10-25。用户要求结合 `design-taste-frontend`、`impeccable` 与既有设计档案，在结构相对一致的前提下重设计，并确认「纸张、深青、细金线，整体更精致克制」的穆夏书册方向。

## 交付内容

投递簿仍按品牌顶栏、统计、标题与新增、搜索排序、状态筛选、公司分组和岗位行组织；保留分页、置顶、状态修改、链接操作和详情抽屉。登录/注册仍为左图右表单，欢迎层仍为左人物右信息，个人主页保留账号、登录状态、数据概览和原有内容。

本轮重做的是视觉系统：

- 纸张底 `#f1eee5`、工作页 `#fffef9`、松针深青 `#244c40` / `#1b3d33`、细金线 `#cab990` / `#ae9765`；语义状态与用户自定义颜色仍服务实际记录。
- 宋体题名、Georgia 字标、系统无衬线界面文字。工作页的主要文字为 13–14px，日期、更新时间等辅助信息为 11–12px。
- 去除渐变字标、模拟噪点纸纹、多层套框与统计奖章；通过字级、列对齐、留白和单层纸面建立层次。头像保留真实进度，改用细 SVG 弧线与淡色内核。
- 登录和注册共用 `AuthLayout.tsx`：深青插图页与白纸表单拼成一本书的两页；手机改为缩微版画与品牌刊头。
- 欢迎层复用人物版画，数字统计改为简洁排版。移动端构图更紧凑，短视口可滚动。
- 个人主页由多张重复卡片改为一张纸上的连续分区；详情页使用下划线标签，表单和题目面板统一字级、颜色与控件尺度。
- 底部邮箱与退出入口使用独立栏，投递列表在专属区域内滚动，两者不相互覆盖；320px 时为状态徽章与行内操作分别保留空间。
- 认证占位文字使用不透明的辅助墨色；搜索只保留一个有无障碍名称的清除按钮。题目截图预览补齐模态语义、Esc、关闭按钮与焦点回归。
