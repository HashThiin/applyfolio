## 一、这一轮解决什么

两个需求，一句话概括：

1. **「不只是收录的 12 网站，所有应用内打开校招官网都能用该扩展」** —— 原来扩展只在 12 家写死的站点自动出卡片，其它站点要用户自己知道「可以点图标」；
2. **「搜索出的校招官网根据匹配度直接点进去」** —— 原来是「输入企业名 → 跳到搜索引擎结果页 → 用户自己在结果里挑官网」，多绕一步且容易点进招聘软件。

### 2.2 三条注入路径，权限逐级放大

| 路径 | 覆盖范围 | 权限代价 | 用户操作 |
| --- | --- | --- | --- |
| `content_scripts` 静态白名单 | 内置 32 家 | 无（`matches` 写在 manifest 里） | 无，进页面就出卡片 |
| 工具栏图标 / `Alt+Shift+A` / 右键菜单 | **任意站点** | `activeTab`（只对这一次操作的标签生效） | 点一下 |
| 「全站自动」（可选，默认关） | **任意站点** | `optional_host_permissions: *://*/*`，用户在设置页手动授权 | 一次授权，长期自动 |

这里刻意**没有**把 `*://*/*` 写进 `permissions`：那会让浏览器安装时就提示「读取和更改你在所访问网站上的所有数据」，与项目约定 22（扩展不申请宽权限）冲突。做成可选授权后，默认装上是零宽权限，想全自动的用户自己点一下，并且随时可关。

### 2.3 「全站自动」的实现要点

- `chrome.permissions.request()` **必须在用户手势里同步发起**：`options.js` 里点按钮时先拿到 `granted` 缓存值再直接调用，绝不在前面 `await` —— 一旦 await，手势标记丢失，Chrome 会直接拒绝且不弹框。
- 授权成功后由 `chrome.permissions.onAdded` → `syncAllSitesScript()` 调 `chrome.scripting.registerContentScripts({ id: 'af-all-sites', matches: ['*://*/*'] })`；撤销走 `onRemoved` → `unregisterContentScripts`。注册前先 `getRegisteredContentScripts({ ids })` 判空，重复注册会抛错。
- **双层注入会撞名**：32 站静态注入与「全站自动」动态注入会在同一站点各跑一次。`panel.js` 有 `__AF_PANEL__` 守卫；`sites.js` 原来把 `const ROLE/JD` 放在顶层，第二次注入会 `SyntaxError: Identifier has already been declared`，本轮已整体包进 IIFE。

### 2.4 卡片与设置页

- 卡片底部加「设置」按钮：内容脚本调不动 `chrome.permissions`，所以 `sendMessage({ type: 'af:open-options' })` → background `openOptionsPage()`。
- 新增 `options.html` / `options.css` / `options.js`：全站自动开关、32 家名单、三条入口说明、快捷键改法、卡片不出现的三种原因（`edge://` 不能注入 / Edge 增强安全模式「严格」/ 改过文件要重新加载）。

## 三、找官网：从「跳搜索引擎」到「按匹配度直达」

### 3.1 打分规则（`lib/jobSearch.ts`）

企业名先归一化：去空格与 `·・-_()（）`，再去掉尾巴 `股份 / 集团 / 有限 / 责任 / 公司 / 控股`。然后逐条比对：

| 档位 | 分数 | 例子 |
| --- | --- | --- |
| 名称一致 | 100 | `腾讯` → 腾讯 |
| 别名一致 | 95 | `Tencent` / `tx` → 腾讯；`byd` → 比亚迪；`b站` → 哔哩哔哩 |
| 前缀命中 | 88 / 84 | `腾讯科技` → 腾讯（88 是「输入是名字的前缀」） |
| 包含 | 72 / 68 | `银行` → 工商银行 / 建设银行 / 招商银行 |

别名命中统一降 5 分并标成「别名命中」，保证正式名在同分时排前面；`单字输入`只认完全一致与前缀，避免「华」命中一堆。排序：分数降序 → 名字短者优先 → 中文排序。

### 3.2 界面行为

- 输入企业名，下面直接出**前 6 条匹配清单**，每行是「序号 + 企业名 + 主域名 + 匹配档位」，点哪条进哪条；
- **回车 / 主按钮进第一条**（按钮文案会变成「进腾讯」），不再默认甩去搜索结果页；
- 一条都没命中才退回三引擎搜索，并明确提示「内置清单里没有这家企业」；
- 输入为空时展示前 6 条常用，不带匹配标签。

## 六、边界与下一步

- **扩展仍要手工加载**（未上架商店），改完文件要到扩展管理页点「重新加载」；版本号已升到 0.2.0，重载后可在扩展卡片看到。
- **新增 20 家用的是通用候选类名**，不像前 12 家逐个摸过；提取不准时卡片里可改可复制，脏就回报具体站点页面补 `sites.js`。
- **匹配库只覆盖 32 家**，覆盖不了「所有企业」。没命中时仍然回到「三引擎搜 `{企业} 校园招聘 官网`」这条老路 —— 这是有意的：宁可让用户去搜索引擎确认，也不要在应用里编造一个可能错的官网入口。
- 国家电网（`zhaopin.sgcc.com.cn` 返 412）等被 WAF 拦机器请求的站点，浏览器里能正常打开，但下一次批量核对时同样拿不到 200 —— 这类只能靠人工确认后再收录。
