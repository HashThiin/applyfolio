## 三、Edge Function `analyze-job`

文件 `supabase/functions/analyze-job/index.ts`（Deno，`jsr:@supabase/supabase-js@2`）。

处理顺序：CORS/OPTIONS → 只收 POST → 校验 `Bearer` → 用**调用者 JWT** 建 client（读库与下载简历都走 RLS）→ `getUser()` → 校验 JD 长度 → 检查 `DEEPSEEK_API_KEY` → 读简历 → 调 DeepSeek → `normalizeAdvice()` 收敛 → 返回 `{ advice }`。

- **简历来源**：`user_profiles.resume_text` 优先；为空则按 `resume_path` 下载原件——TXT/MD 直接解码，PDF 用 `npm:unpdf` 动态 `import`（省冷启动内存），截断到 24000 字。
- **模型**：`deepseek-chat`，`response_format: { type: 'json_object' }`，`temperature 0.3`，`max_tokens 1600`，`AbortSignal.timeout(90_000)`。
- **不可全信模型输出**：`normalizeAdvice` 逐字段收敛——score 夹到 0–100，列表限条数与单条字数，`resumeEdits` 最多 6 条，`summary` 为空即判失败。
- **六种可展示的降级码**：`AI_NOT_CONFIGURED`(503) / `RESUME_MISSING`(422) / `RESUME_UNREADABLE`(422) / `JD_TOO_SHORT`(422) / `AI_UPSTREAM_ERROR`(502) / `AI_BAD_RESPONSE`(502)；另有 `UNAUTHORIZED` / `SERVER_MISCONFIGURED` / `PROFILE_READ_FAILED`。

- **`IntentPanel.tsx`**（Drawer）：两段式表单。
