## 一、设计主张

**一句话**：把「校招投递记录」这件事，做成一张**装裱在版画纸上的手账簿页**——纸有纤维，页有金线，罗盘指北。

三条不可让渡的原则（后续任何改动都应先过这三关）：

1. **线条支配形体，金箔只做描边。**
   穆夏的形体是线条围出来的，不是色块堆出来的。界面里所有结构（框、拱、分隔、奖章）都由 1px 左右的金线/墨线完成；金色**永不**用于大面积填充，只出现在字标、描边、分隔线、奖章刻度。
2. **结构即信息，装饰不解释。**
   每一条金线都必须对应一次内容切分：马赛克带＝报头与正文的分界；金线分隔＝标题与摘要的分界；罗盘奖章＝统计单位的边界。**不允许**出现"因为空所以加一个花纹"的装饰。
3. **全站只允许一处高音。**
   唯一的整版海报位是**登录后的欢迎层**。其余页面（列表、表单、抽屉、弹窗）一律回到纸面与墨字，安静、克制、可长期凝视。这就是 Chanel 式"出门前摘掉一件配饰"。

## 二、风格坐标：穆夏语汇 → 界面规则

| 穆夏原作特征 | 本项目中的界面规则 | 落点 |
| --- | --- | --- |
| 线条（ligne）包住形体，轮廓清晰 | 所有容器用**描边**成立，不用投影成立 | `Plate` / `ArchPanel` / `PosterFrame` |
| 粉彩淡彩（pastel）与金箔并置 | 底色为象牙纸，金只做细线点缀；语义色降饱和 | 令牌表第三节 |
| 拜占庭马赛克 | 菱形金瓦饰带，作为**段落结构线** | `MosaicBand` |
| 圆拱 / 光环的神圣几何 | 肖像与植物一律置于**双层金线圆拱**内 | `ArchPanel` |
| 女性与自然共生（常春藤、铃兰、罂粟） | 主视觉为"少女＋罗盘＋马赛克光环"版画 | `mucha-compass.jpg` |
| 非对称构图（一侧重、一侧轻） | 登录/注册：左植物版画、右窄表单；欢迎层：左拱图、右信息 | 第六节线框 |

## 三、色彩系统

底色 = 象牙纸 `#f7f2e6`，其上叠加：纸纹噪点（feTurbulence，opacity 0.05）+ 四道极淡径向光晕（金 / 杏橙 / 深青 / 藕紫）。`background-attachment: fixed`，滚动时纸不动、字在动，像隔着画框看稿。

### 3.1 品牌深青（全站锚色）

| 令牌 | Hex | 用途 |
| --- | --- | --- |
| `brand-800` | `#085844` | 主按钮底色（与白字 8.4:1） |
| `brand-700` | `#046f55` | 按钮 hover、链接文字、全局焦点环 |
| `brand-600` | `#058a67` | 输入框聚焦描边 |
| `brand-50` | `#eefbf6` | 极淡底（仅在需要区分选中态时） |

### 3.2 暖中性（墨）

| 令牌 | Hex | 对比度（对纸底） | 用途 |
| --- | --- | --- | --- |
| `ink-900` | `#1f1e1a` | 15.6:1 | 标题、正文主色 |
| `ink-700` | `#4a4842` | 8.6:1 | 表单标签 |
| `ink-600` | `#5f5d54` | **≈6.0:1** | **所有辅助小字的上限色**（日期、说明、尾注、奖章标签） |
| `ink-500` | `#7b786d` | 3.96:1 | 仅用于非信息性文字（如次要链接的默认态） |
| `ink-400` | `#9d9a8f` | 2.52:1 | **禁止承载文字**，只允许做图标默认色 / 分隔 |
| `ink-300` | `#c3c0b6` | — | 虚线上传框描边 |
| `ink-200` | `#dedcd5` | — | 输入框默认描边 |

## 四、字体系统

只用两族，角色互斥，不混用：

| 令牌 | 字族栈 | 角色 |
| --- | --- | --- |
| `--font-sans` | PingFang SC / Microsoft YaHei / Helvetica Neue | 所有界面文字：正文、表单、按钮、表格 |
| `--font-display` | KaiTi / STKaiti / 楷体 / Georgia | **展示行**：页面名、问候语、弹层标题、奖章数字 |
| `--font-wordmark` | Georgia / Times New Roman / Songti SC | **只给字标 JobCompass** |

### 4.1 层级表

| 层级 | 规格 | 用途 |
| --- | --- | --- |
| 报头字标 | 19px / `font-wordmark` / 金渐变 | 主应用页眉 |
| 海报问候 | 28px→32px（sm）/ `font-display` / 行高 1.25 | 欢迎层唯一大标题 |
| 页面/弹层标题 | 22px 登录注册；17px 抽屉与弹窗 / `font-display` | 标题即"版画题名" |
| 区块说明 | 13px / `ink-600` / 行高 relaxed | 导语、旁白 |
| 界面正文 | 13–14px / `font-sans` | 列表、表单 |
| 辅助小字 | 10–12px / **`ink-600`** / letter-spacing 0.08em（仅短标签） | 日期、尾注、奖章标签 |

楷体只承担"可被大声读出来"的句子；任何需要被扫描、被填写的文字都回落到无衬线。这样版画气质只存在于标题层，操作层依然清晰。

## 五、装饰系统（`src/components/Ornament.tsx`）

8 个无状态纯 SVG 组件。**全部使用 `currentColor`**，颜色由外层 `text-gilt-*` 控制，透明度由 `/NN` 控制——换色不需要改组件。

| 组件 | viewBox / 尺寸 | 结构 | 用途 |
| --- | --- | --- | --- |
| `CornerFlourish` | 140×140，渲染 `h-14 w-14` | 双反向蔓茎 + 2 叶 + 2 花苞 + 点 | 画框四角、欢迎层卡片四角（靠 `rotate-90/180/-90` 复用单象限） |
| `GiltDivider` | 280×16，渲染 `h-3 w-32~44` | 两端收细发丝线 + 双侧叶片 + 中央菱形针 | 标题与内容之间的分界 |
| `MosaicBand` | 高 8px，宽 100% | SVG pattern 24×8：大菱瓦 + 双侧菱点 | 报头底边、欢迎层卡底边（拜占庭饰带） |
| `Plate` | 铺满父容器 | 外框 `gilt-400/45` + 内框 `gilt-200/50`（inset 5px）+ 四角 8px L 刻线 | **替代卡片**：主列表、表单、主页区块 |
| `ArchPanel` | 由 `imageClassName` 决定 | 双层圆拱（`rounded-t-[999px]` 嵌套）+ 拱顶 45° 菱饰 | 人物/植物版画框 |
| `Medallion` | 48×48 SVG，渲染 44×44 | 双环（实线 0.9 + 虚线点刻 0.7）+ 上下罗盘针 + `font-display` 数字 | 统计单位：总投递 / 进行中 / Offer |
| `PosterFrame` | `fixed inset-2 md:inset-3` | 双细金线框 + 四角角花（`gilt-600/45`） | 全站视口画框（`sm+` 显示，移动端收起以免压内容） |
| `Wordmark` | 内联 | `.jc-gilt-text` 金属渐变 + `font-wordmark` | 品牌名，全站仅此一处渐变文字 |

### 5.1 金属渐变（`.jc-gilt-text`）

```
linear-gradient(104deg,
  #8f6526 0%, #d8b66a 24%, #f2e0ab 44%,
  #b8863f 60%, #e7cd8b 80%, #a97b33 100%)
```
`background-clip: text` + `-webkit-text-fill-color: transparent`，回退色 `#a97b33`；`forced-colors` 下还原为 `currentColor`。明暗交替 6 段模拟金箔受光，避免"单色黄字"的廉价感。

### 5.2 圆拱的画法

不画路径，用**嵌套圆角**：外层 `rounded-t-[999px] border gilt-400/70 p-[6px]` → 内层 `border gilt-200/80 p-[4px]` → 图像容器 `overflow-hidden rounded-t-[999px]`。三层叠加得到"石拱 + 两道金线"的厚度，且无论宽高比如何都保持完美半圆收头。

## 七、唯一高音原则与减件记录

设计过程中主动摘掉的东西（保留在本节，避免以后被重新加回来）：

| 摘掉 | 原因 |
| --- | --- |
| 每张列表卡片四角的角花 | 角花属于"画框"，一页出现 20 次等于没有角花 |
| 抽屉/弹窗标题旁的金线分隔 | 浮层已有清晰边界，再加线即噪音 |
| 欢迎层逐项入场动画 | 一次整卡入场即可，逐项动画是 AI 默认腔 |
| 统计项的副标题英译 / 全大写标签 | 中文界面不需要装饰性英文 |
| 金色大面积底色按钮 | 金只做线；主按钮用深青底 + 内嵌金线 |
| 列表卡片统一阴影 | 改为 hover 时 `gilt-100/40` 底色，层级交给描边 |

## 八、动效

- **有且只有一次编排**：欢迎层整卡入场（`opacity` + `translateY` + `scale`，280ms）。
- 其余全部为"回应动作"的动效：抽屉 `jc-slide-in` 220ms、弹窗 `jc-pop-in` 200ms、折叠区 `jc-collapse-in` 180ms、Toast `jc-fade-in` 180ms。缓动统一 `cubic-bezier(0.22, 1, 0.36, 1)`。
- 按钮 hover：底色 `brand-800 → brand-700`，箭头 `translate-x-0.5`。
- `prefers-reduced-motion: reduce` 下所有 `jc-*` 动画为 `none`。

## 九、可及性

| 项目 | 措施 |
| --- | --- |
| 文字对比度 | 信息性小字统一 `ink-600`（≈6.0:1）；`ink-400`(2.52:1)/`ink-500`(3.96:1) 降级为图标与装饰专用 |
| 焦点可见 | 全局 `*:focus-visible { outline: 2px solid #046f55; offset 2px }`；输入框另加 `ring-brand-600/15`（与暖金同族深青，不撞色） |
| 高对比模式 | `forced-colors: active` 下 `.jc-gilt-text` 回退 `currentColor`，金渐变不会变成不可见文字 |
| 动效敏感 | 见第八节 |
| 装饰语义 | 全部装饰 SVG `aria-hidden`；`PosterFrame` 为 `pointer-events-none`，不拦截点击 |
| 图像替代 | 主视觉 img 均有描述性 alt（植物/人物 + 元素），移动端重复图用 `alt="" aria-hidden` |
| 触控尺寸 | 图标按钮 `p-1.5`（≈32px）+ 行高 36px；主按钮 44px |

## 十二、反模式清单（改代码前先读）

1. 不要用大面积金色、渐变色块或金色按钮底。
2. 不要在列表卡片、抽屉、弹窗里加角花 / 马赛克带。
3. 不要用 `gilt-*` 承载正文文字。
4. 不要把信息性小字压回 `ink-400/500`。
5. 不要给每个区块加 fade-slide-up 入场；动效只回应动作，或一次性编排。
6. 不要新增第三套字体；楷体与无衬线不得互相越界（标题/操作）。
7. 不要用统一圆角 + 统一阴影做层级；层级用线和留白。
8. 不要用 ALL-CAPS eyebrow、01/02/03 编号、`A · B · C` 元信息串来"显得专业"。
